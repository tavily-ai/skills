# Tavily in OpenCode

When you run `tvly search`, `tvly extract`, `tvly map`, `tvly crawl` or `tvly research`, add `--client-name opencode` after the subcommand, for example `tvly search "query" --json --client-name opencode`.

If `tvly` is missing or not signed in, follow the setup reference in the `tavily-search` skill.
