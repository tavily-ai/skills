# Tavily

When a task depends on information outside this repository, such as current documentation, changelogs, GitHub
issues, error messages, release notes, news or any fact past your training data, use the Tavily tools instead of
answering from memory. Use the `tavily-search` skill for how to search, read pages, map sites and crawl them.

Cite the URLs you relied on. If a Tavily call fails with an authentication error, ask the user to sign in to the
Tavily MCP server again rather than working around it.
